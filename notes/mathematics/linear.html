03 Graphical Method — ପଦକ୍ରମ

1
ଦୁଇଟି equation କୁ ଯଥାସମ୍ଭବ y = ... form ରେ ଲେଖ।
2
ପ୍ରତ୍ୟେକ equation ପାଇଁ କିଛି x-values ନେଇ corresponding y-values ବାହାର କର।
3

4
Intersection point ର coordinates ପଢ଼ି solution ଲେଖ।
EXAMPLE 1
x + 2y − 3 = 0
2x − y − 1 = 0
y = ½(3−x)     ;     y = 2x−1
1
ପ୍ରଥମ line ପାଇଁ points: (1,1), (3,0) ଇତ୍ୟାଦି।
2
ଦ୍ୱିତୀୟ line ପାଇଁ points: (1,1), (2,3) ଇତ୍ୟାଦି।
3
Graph ରେ common point (1,1)।
∴ Solution = (1,1)

06 Method of Substitution

🔁
ଏହି method ରେ ଗୋଟିଏ equation ରୁ ଗୋଟିଏ variable କୁ isolate କରି, ସେହି value କୁ ଅନ୍ୟ equation ରେ substitute କରାଯାଏ।

EXAMPLE 5
5x + 2y + 2 = 0
3x + 4y − 10 = 0
1
ପ୍ରଥମ equation ରୁ y = −½(5x+2)।
2
ଏହାକୁ second equation ରେ substitute କର।
3
ସରଳୀକରଣ ପରେ x = −2।
4
ପୁଣି substitute କଲେ y = 4।
∴ (x,y)=(-2,4)
Verification: ମିଳିଥିବା x,y values କୁ ଦୁଇଟି original equations ରେ ପକାଇ check କର।

07 Method of Elimination

➖
ଏବେ coefficient କୁ ଏଭଳି ବଦଳାଇବା ଯାହାଦ୍ୱାରା x କିମ୍ବା y ର coefficient ସମାନ ହେବ। ପରେ add/subtract କରି ସେହି variable କୁ eliminate କରିବା।

EXAMPLE 6
2x + 3y − 8 = 0
3x + y − 5 = 0
3×(i): 6x+9y−24=0
2×(ii): 6x+2y−10=0
Subtract → 7y−14=0 → y=2
Substitute → 2x+6−8=0 → x=1
∴ (x,y)=(1,2)

08 Method of Cross Multiplication

✖️
ଏହି method ରେ standard form ର coefficients ରୁ ଗଠିତ formula ବ୍ୟବହାର କରି x ଓ y କୁ ନିର୍ଣ୍ଣୟ କରାଯାଏ।
FORMULA

EXAMPLE 7

Cross multiplication → x = 2, y = 1
∴ (x,y)=(2,1)

11 Cramer's Rule

Δ
Determinant ବ୍ୟବହାର କରି simultaneous equations ର solution ବାହାର କରିବାକୁ Cramer's Rule ବ୍ୟବହାର କରାଯାଏ।
THREE DETERMINANTS
Δ = |a₁  b₁ ; a₂  b₂|
Δₓ = |−c₁  b₁ ; −c₂  b₂|
Δᵧ = |a₁  −c₁ ; a₂  −c₂|
x = Δₓ/Δ     y = Δᵧ/Δ
Find Δ
→
Find Δₓ
→
Find Δᵧ
→
x=Δₓ/Δ
+
y=Δᵧ/Δ
EXAMPLE 10
x + 2y − 1 = 0
2x − 3y − 1 = 0
Δ = |1  2; 2  −3| = −7
Δₓ = |1  2; 1  −3| = −5
Δᵧ = |1  1; 2  1| = −1
x=5/7    ;    y=1/7

13 Problem-Solving Checklist

1
Given: ପ୍ରଶ୍ନରେ କ’ଣ ଦିଆଯାଇଛି?
2
Let: ଅଜଣା ରାଶିକୁ x,y ଧର।
3
Equations: ଦୁଇଟି condition ରୁ ଦୁଇଟି equations ବନା।
4
Method: Substitution / Elimination / Cross Multiplication / Cramer's Rule ମଧ୍ୟରୁ suitable method ନିଅ।
5
Verification: ମିଳିଥିବା x,y କୁ original equations ରେ check କର।
6
Answer: Question ଯେଉଁ quantity ପଚାରିଛି, ସେହି ଭାବରେ final answer ଲେଖ।
⚠️ Common Calculation Checks
  • Equation କୁ standard form ରେ ଆଣିବା ବେଳେ sign ଭୁଲ କରନ୍ତୁ ନାହିଁ।
  • Substitution ପରେ bracket ସଠିକ୍ ଭାବେ expand କରନ୍ତୁ।
  • Elimination ରେ ପୂରା equation କୁ multiply କରନ୍ତୁ।
  • Cross multiplication ରେ coefficient ର order ଠିକ୍ ରଖନ୍ତୁ।
  • Determinant ରେ ad−bc ମନେ ରଖନ୍ତୁ।
  • Final answer କୁ original equations ରେ verify କରନ୍ତୁ।
