ଦ୍ୱିଘାତ ବହୁପଦୀଦ୍ୱିଘାତ ସମୀକରଣମୂଳବିଭେଦକ Dଗଠନ
ଶିକ୍ଷକଙ୍କ ଆରମ୍ଭ: ପ୍ରଥମେ ଆମେ ଦ୍ୱିଘାତ ସମୀକରଣ କ’ଣ ତାହା ବୁଝିବା। ତାପରେ ଦୁଇଟି ମୂଳ କିପରି ବାହାରେ, ସେହି ମୂଳର ପ୍ରକୃତି କିପରି ଜାଣିବା, ଏବଂ ମୂଳ ଦିଆଯାଇଥିଲେ ସମୀକରଣ କିପରି ଗଠନ କରିବା—ସବୁକୁ ପଦକ୍ଷେପରେ ଶିଖିବା।

2.1 ପରିଚୟ — Introduction

ଯେଉଁ ବହୁପଦୀର ସାଧାରଣ ରୂପ P(x)=ax²+bx+c, ଯେଉଁଠାରେ a≠0, ତାହାକୁ ଦ୍ୱିଘାତ ବହୁପଦୀ (Quadratic Polynomial) କୁହାଯାଏ।

P(x)=ax²+bx+c,   a≠0

ଏହି ବହୁପଦୀକୁ ଶୂନ୍ୟର ସମାନ କଲେ ମିଳେ:

ax²+bx+c=0,   a≠0
ଏହା ହେଉଛି ଦ୍ୱିଘାତ ସମୀକରଣ। ଏଠାରେ a, b, c ହେଉଛି ସମୀକରଣର ସହଗ (coefficients) ଏବଂ a≠0।

ମୂଳ / Zero କ’ଣ?

ଯଦି x ର କୌଣସି ମାନ ପାଇଁ P(x)=0 ହୁଏ, ସେହି x ମାନକୁ ବହୁପଦୀର ମୂଳ (zero) କୁହାଯାଏ।

ଉଦାହରଣ: x²−5x+6=0 କୁ ଗୁଣନୀୟକରଣ କଲେ (x−2)(x−3)=0। ତେଣୁ x=2 କିମ୍ବା x=3 ହେଉଛି ମୂଳ।

2.2 ବର୍ଗ ପୂରଣ ପ୍ରଣାଳୀ — Completing the Square

ax²+bx+c=0
1
x² + (b/a)x + c/a = 0
2
x² + 2·(b/2a)x + c/a = 0
3
ବାମପଟେ ବର୍ଗ ପୂରଣ ପାଇଁ (b/2a)² ଯୋଗ କରି ଡାହାଣପଟେ ମଧ୍ୟ ସମାନ ପରିମାଣ ଯୋଗ କରିବା।
(x + b/2a)² = (b²−4ac)/(4a²)
4
ବର୍ଗମୂଳ ନେଲେ:
x + b/2a = ±√(b²−4ac)/(2a)
5
ଶେଷରେ:
x = (−b ± √(b²−4ac))/(2a)
ଦୁଇଟି ମୂଳ: α = (−b+√(b²−4ac))/(2a),   β = (−b−√(b²−4ac))/(2a)
ମନେ ରଖନ୍ତୁ: ± ଥିବାରୁ ଦୁଇଟି ସମ୍ଭାବ୍ୟ ମୂଳ ମିଳେ।

🧮 ଦ୍ୱିଘାତ ସୂତ୍ର — Quadratic Formula

x = (−b ± √(b²−4ac))/(2a)
ଚିହ୍ନଅର୍ଥ
ax² ର ସହଗ
bx ର ସହଗ
cଧ୍ରୁବ ପଦ
b²−4acବିଭେଦକ (Discriminant), D
ଏହି ସୂତ୍ରରେ ମାନ ବସାଇବା ସମୟରେ +/− ଚିହ୍ନ ଓ ବନ୍ଧନୀକୁ ସାବଧାନରେ ରଖନ୍ତୁ।

📝 Source Example 1 — 6x²+11x+3=0

ପ୍ରଶ୍ନ: 6x²+11x+3=0 ସମୀକରଣର ମୂଳ ନିର୍ଣ୍ଣୟ କର।

ଦିଆଯାଇଛି: a=6, b=11, c=3

ବାହାର କରିବା: x ର ଦୁଇଟି ମୂଳ

ସୂତ୍ର:

x=(−b±√(b²−4ac))/(2a)
1
D=b²−4ac = 11²−4×6×3 = 121−72 = 49
2
√D=√49=7
3
x=(−11±7)/(12)
4
x=(−11+7)/12 = −4/12 = −1/3
5
x=(−11−7)/12 = −18/12 = −3/2
ଉତ୍ତର: x = −1/3 ଏବଂ x = −3/2

📝 Source Example 2 — x²+2x−63=0

ଦିଆଯାଇଛି: a=1, b=2, c=−63

1
α=(−2+√(2²−4×1×(−63)))/(2×1)
2
= (−2+√(4+252))/2 = (−2+16)/2 = 7
3
β=(−2−16)/2 = −9
ଉତ୍ତର: α=7, β=−9

2.3 ବିଭେଦକ — Discriminant

D = b² − 4ac

ଦ୍ୱିଘାତ ସମୀକରଣ ax²+bx+c=0 ପାଇଁ D ର ମାନ ଦେଖି ମୂଳର ପ୍ରକୃତି ଜାଣିହୁଏ।

D>0
→
ଦୁଇଟି ବାସ୍ତବ ଓ ଭିନ୍ନ ମୂଳ
D=0
→
ଦୁଇଟି ସମାନ ବାସ୍ତବ ମୂଳ
D<0
→
ବାସ୍ତବ ମୂଳ ନାହିଁ
ଏହାକୁ ମନେ ରଖିବା ପାଇଁ: Plus → ଦୁଇ ଭିନ୍ନ, Zero → ସମାନ, Minus → ବାସ୍ତବ ନାହିଁ।

2.4 ମୂଳଗୁଡ଼ିକର ପ୍ରକୃତି — Nature of Roots

Dମୂଳର ପ୍ରକୃତିମୂଳ
D>0ଦୁଇଟି ବାସ୍ତବ ଓ ଭିନ୍ନ ମୂଳ(−b+√D)/2a, (−b−√D)/2a
D=0ଦୁଇଟି ସମାନ ବାସ୍ତବ ମୂଳ−b/2a
D<0ବାସ୍ତବ ମୂଳ ନାହିଁବାସ୍ତବ ମୂଳ ନାହିଁ

ଉଦାହରଣ: x²−2x−8=0 ପାଇଁ a=1,b=−2,c=−8.

D=(−2)²−4(1)(−8)=4+32=36>0
ତେଣୁ ଏହାର ଦୁଇଟି ବାସ୍ତବ ଓ ଭିନ୍ନ ମୂଳ ଅଛି।

2.5 ମୂଳ ଓ ସହଗମାନଙ୍କ ମଧ୍ୟରେ ସମ୍ପର୍କ

ଯଦି ax²+bx+c=0 ର ମୂଳ α ଓ β, ତେବେ:

α+β = −b/a
αβ = c/a
ଏହି ଦୁଇଟି ସମ୍ପର୍କ ବହୁତ ଜରୁରୀ। ମୂଳ ସିଧାସଳଖ ବାହାର କରିବା ଦରକାର ନଥିଲେ ମଧ୍ୟ α+β ଓ αβ ବାହାର କରିହୁଏ।

📝 Source Example 4 — 25x²+30x+7=0

ଦିଆଯାଇଛି: a=25, b=30, c=7

α+β=−b/a=−30/25=−6/5
αβ=c/a=7/25
ଉତ୍ତର: α+β=−6/5, αβ=7/25

2.6 କିଛି ଜଣାଶୁଣା ଫଳ — Some Known Results

ଯଦି α+β=−b/a ଏବଂ αβ=c/a, ତେବେ:

α−β = ±√((α+β)²−4αβ) = ±√D/a
α²+β² = (α+β)²−2αβ = (b²−2ac)/a²
α²−β² = (α+β)(α−β)
α³+β³ = (α+β)³−3αβ(α+β)
α/β + β/α = ((α+β)²−2αβ)/(αβ)
ଏଠାରେ ପ୍ରଥମେ α+β ଓ αβ ବାହାର କରନ୍ତୁ। ତାପରେ ଆବଶ୍ୟକ ଫଳରେ ସେଗୁଡ଼ିକ ବସାନ୍ତୁ।

📝 Source Example 5 — 2x²−6x+3=0

ଦିଆଯାଇଛି: a=2,b=−6,c=3

α+β=−b/a=6/2=3
αβ=c/a=3/2

ତେଣୁ:

α/β + β/α = ((α+β)²−2αβ)/(αβ)
= (3²−2×3/2)/(3/2) = 4
ଉତ୍ତର: 4

2.7 ମୂଳ ଦିଆଯାଇଲେ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ

ଯଦି ଏକ ଦ୍ୱିଘାତ ସମୀକରଣର ମୂଳ α ଓ β, ତେବେ:

x²−(α+β)x+αβ=0

କାରଣ:

(x−α)(x−β)=0
⇒ x²−(α+β)x+αβ=0
ଅର୍ଥାତ୍ ମୂଳ ଦିଆଯାଇଥିଲେ ପ୍ରଥମେ α+β ଓ αβ ବାହାର କରି ଏହି ରୂପରେ ସମୀକରଣ ଲେଖନ୍ତୁ।

📝 Source Example 6 — ମୂଳର ଯୋଗ 5 ଓ ଗୁଣଫଳ 3

ଦିଆଯାଇଛି: α+β=5, αβ=3

x²−(α+β)x+αβ=0
⇒ x²−5x+3=0
ଗଠିତ ଦ୍ୱିଘାତ ସମୀକରଣ: x²−5x+3=0

📝 Source Example 7 — ମୂଳର ଯୋଗ 2 ଓ ଗୁଣଫଳ −1

ଦିଆଯାଇଛି: α+β=2, αβ=−1

x²−2x−1=0
ଉତ୍ତର: x²−2x−1=0

📝 Source Example 8 — α+β ଓ αβ ସମାନ

ସମୀକରଣ: ax²+4x+6a=0, a≠0.

α+β=−4/a
αβ=6

Source ର ସମ୍ପର୍କ ଅନୁସାରେ α+β=αβ ହେଲେ:

−4/a=6 ⇒ a=−2/3
ଉତ୍ତର: a=−2/3

2.8 ଦ୍ୱିଘାତ ରୂପକୁ ପରିବର୍ତ୍ତନ — Equations Reducible to Quadratic Form

କେତେକ ସମୀକରଣ ସିଧାସଳଖ ax²+bx+c=0 ଭଳି ଦେଖାଯାଏ ନାହିଁ। ଉପଯୁକ୍ତ substitution କରି ସେଗୁଡ଼ିକୁ ଦ୍ୱିଘାତ ରୂପକୁ ଆଣାଯାଏ।

ଦିଆଯାଇଥିବା ସମୀକରଣ
→
ନୂଆ ଚଳ t / y
→
ଦ୍ୱିଘାତ ସମୀକରଣ
→
t / y ର ମୂଳ
→
x ର ମୂଳ

📝 Source Example 9 — x⁴−21x²+20=0

ପଦ 1: x² = y ନିଅ। ତେବେ x⁴=y².

y²−21y+20=0

ପଦ 2: ଏହା ଏକ ଦ୍ୱିଘାତ ସମୀକରଣ।

D=(−21)²−4×1×20=441−80=361=19²

ପଦ 3:

y=(21±19)/2 ⇒ y=20 କିମ୍ବା y=1

ପଦ 4: y=x² ଥିବାରୁ:

x²=20 ⇒ x=±2√5
x²=1 ⇒ x=±1
ଉତ୍ତର: x=±1, ±2√5

📝 Source Example 10 — 4(x−1/x)²+8(x+1/x)−29=0

Substitution: y=x+1/x.

(x−1/x)²=(x+1/x)²−4=y²−4
1
4(y²−4)+8y−29=0
2
4y²+8y−45=0
3
ଦ୍ୱିଘାତ ସୂତ୍ର ଦ୍ୱାରା y=5/2 କିମ୍ବା y=−9/2.
4
ପ୍ରତ୍ୟେକ y ମାନକୁ x+1/x=y ରେ ବସାଇ x ବାହାର କରିବା।
ଏହି ପ୍ରକାରର ପ୍ରଶ୍ନରେ ପ୍ରଥମେ substitution କରି ସମୀକରଣକୁ ସରଳ ଦ୍ୱିଘାତ ରୂପକୁ ଆଣନ୍ତୁ।

📝 Source Example 11 — √(x/(1−x)) + √((1−x)/x) = 13/6

Source ରେ ଏହି ପ୍ରଶ୍ନକୁ substitution ଦ୍ୱାରା ଦ୍ୱିଘାତ ରୂପକୁ ଆଣାଯାଇଛି।

y + 1/y = 13/6
⇒ 6y²−13y+6=0

ତାପରେ ଦ୍ୱିଘାତ ସୂତ୍ର ଦ୍ୱାରା y ର ମୂଳ ବାହାର କରି, ପୁନଃ substitution ରେ x ନିର୍ଣ୍ଣୟ କରାଯାଏ।

ଏଠାରେ ପ୍ରତ୍ୟେକ ରୂପାନ୍ତରଣ ଲେଖିବା ଜରୁରୀ—ମଧ୍ୟର step ଛାଡ଼ିବା ନାହିଁ।

📝 Source Example 12 — ଗୁଣନୀୟକରଣ ଦ୍ୱାରା ପରିବର୍ତ୍ତନ

Source ରେ x(x+5)(x+7)(x+12)+150=0 କୁ ଯୋଡ଼ି-ବିୟୋଗ ଓ ଗୁଣନୀୟକରଣ ଦ୍ୱାରା ଦ୍ୱିଘାତ ରୂପକୁ ଆଣାଯାଇଛି।

x(x+5)(x+7)(x+12)+150=0
⇒ (x²+12x)(x²+12x+35)+150=0
y=x²+12x
⇒ y²+35y+150=0

ଏବେ y ର ମୂଳ ବାହାର କରି ପୁନଃ y=x²+12x ରେ ବସାଇ x ବାହାର କରାଯାଏ।

2.9 ଦ୍ୱିଘାତ ସମୀକରଣର ପ୍ରୟୋଗ — Application

ଦୈନନ୍ଦିନ ଜୀବନର କେତେକ ପରିସ୍ଥିତିରେ ଅଜଣା ରାଶିକୁ x ଧରି, ପରିସ୍ଥିତିରୁ ଏକ ଦ୍ୱିଘାତ ସମୀକରଣ ଗଠନ କରାଯାଏ।

ପ୍ରଶ୍ନର ତଥ୍ୟ
→
ଅଜଣା = x
→
ସମ୍ପର୍କ ସ୍ଥାପନ
→
ଦ୍ୱିଘାତ ସମୀକରଣ
→
x ର ମାନ
→
ଅର୍ଥପୂର୍ଣ୍ଣ ଉତ୍ତର

📝 Source Example 13 — x²−x−90=0

Source ରେ ସମୀକରଣ:

x²−x−90=0
1
x²−10x+9x−90=0
2
x(x−10)+9(x−10)=0
3
(x+9)(x−10)=0

📝 Source Example 14 — ସଂଖ୍ୟାର ଗୁଣନଫଳ ଓ ସମ୍ପର୍କ
