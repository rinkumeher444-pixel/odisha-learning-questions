5.1 ପରିଚୟ — Introduction

ତଥ୍ୟକୁ ସଂଖ୍ୟାତ୍ମକ ତଥ୍ୟ (Numerical Data), ପ୍ରାଥମିକ ତଥ୍ୟ (Primary Data), ଦ୍ୱିତୀୟକ ତଥ୍ୟ (Secondary Data) ଇତ୍ୟାଦି ଭାବରେ ଦେଖାଯାଇପାରେ। ତଥ୍ୟକୁ ସଜାଇବା ପାଇଁ ଆବୃତ୍ତି ବିତରଣ (Frequency Distribution), Histogram, Pie-chart, Pictograph ଆଦି ବ୍ୟବହାର ହୁଏ।

ମୁଖ୍ୟ ଲକ୍ଷ୍ୟ: ବହୁତ ତଥ୍ୟକୁ ସରଳ ଭାବରେ ବୁଝିବା ଏବଂ ଏକ ପ୍ରତିନିଧି ମାନ ନିର୍ଣ୍ଣୟ କରିବା।

5.2 କେନ୍ଦ୍ରୀୟ ପ୍ରବୃତ୍ତିର ମାପ

ଏକ ତଥ୍ୟ ସମୂହକୁ ପ୍ରତିନିଧିତ୍ୱ କରୁଥିବା କେନ୍ଦ୍ରୀୟ ମାନ ତିନୋଟି ମୁଖ୍ୟ ପ୍ରକାରର:

ମାଧ୍ୟମାନ (Mean)

ସମସ୍ତ ମାନର ଯୋଗକୁ ମୋଟ ମାନର ସଂଖ୍ୟା ଦ୍ୱାରା ଭାଗ।

ମଧ୍ୟମା (Median)

ତଥ୍ୟକୁ କ୍ରମରେ ରଖିଲେ ମଧ୍ୟଭାଗର ମାନ।

ବହୁଳକ (Mode)

ସର୍ବାଧିକ ଥର ଘଟୁଥିବା ମାନ।

5.2.1 ମାଧ୍ୟମାନ — Mean

(କ) ବ୍ୟକ୍ତିଗତ ତଥ୍ୟର ମାଧ୍ୟମାନ

ଯଦି ତଥ୍ୟଗୁଡ଼ିକ x₁, x₂, x₃, …, xₙ ହୁଏ, ତେବେ:

M = Σx / n
ଚିହ୍ନଅର୍ଥ
Σxସମସ୍ତ ତଥ୍ୟମାନର ଯୋଗ
nତଥ୍ୟମାନର ମୋଟ ସଂଖ୍ୟା
Mମାଧ୍ୟମାନ
ସହଜ କଥା: ସମସ୍ତ ମାନକୁ ଯୋଗ କରି, କେତୋଟି ମାନ ଅଛି ସେହି ସଂଖ୍ୟାରେ ଭାଗ କଲେ ମାଧ୍ୟମାନ ମିଳେ।

📌 ମାଧ୍ୟମାନର ଅନ୍ୟ ପଦ୍ଧତି — Assumed Mean

ଯେତେବେଳେ ସଂଖ୍ୟାଗୁଡ଼ିକ ବଡ଼ ହୁଏ, ଏକ ସୁବିଧାଜନକ ମାନ A କୁ assumed mean ଭାବେ ନେଇ deviation ବ୍ୟବହାର କରି ଗଣନା ସରଳ କରାଯାଏ।

y = x − A
M = A + Σfy/Σf
A = assumed mean, y = deviation, f = frequency, Σf = ମୋଟ frequency, Σfy = frequency × deviation ର ଯୋଗ।

📌 Step-Deviation Method — ପଦକ୍ଷେପ ବିଚ୍ୟୁତି ପଦ୍ଧତି

ଯେତେବେଳେ class width ସମାନ ଥାଏ, deviation କୁ class width ଦ୍ୱାରା ଭାଗ କରି ଗଣନା ଆହୁରି ସରଳ କରାଯାଏ।

y' = (x−A)/c
M = A + (Σfy'/Σf) × c
A = assumed mean, c = class width, y' = coded deviation.

M = A + (Σfy'/Σf)×c
1
M=35+(−10/100)×10
2
M=35−1
3
M=34.9
ଉତ୍ତର: M = 34.9

5.2.2 ମଧ୍ୟମା — Median

ତଥ୍ୟକୁ ଆରୋହୀ କିମ୍ବା ଅବରୋହୀ କ୍ରମରେ ସଜାଇଲେ ମଧ୍ୟଭାଗର ମାନକୁ ମଧ୍ୟମା କୁହାଯାଏ।

n ବିଜୋଡ଼ → Md = ((n+1)/2)ତମ ମାନ
n ଯୁଗ୍ମ → Md = 1/2 × [n/2 ତମ ମାନ + (n/2+1)ତମ ମାନ]
ପ୍ରଥମ କାମ: ତଥ୍ୟକୁ କ୍ରମରେ ରଖିବା। ତାପରେ n ଯୁଗ୍ମ କି ବିଜୋଡ଼ ତାହା ଦେଖିବା।

📝 ଉଦାହରଣ ୧୧ — Median

ଦିଆଯାଇଥିବା ତଥ୍ୟ: 40, 42, 44, 45, 46, 48, 49.

1

2
n=7, ଯାହା ବିଜୋଡ଼।
3
Median = (7+1)/2 = 4ତମ ମାନ।
4
4ତମ ମାନ = 45.
ଉତ୍ତର: Md=45

Grouped frequency distribution ରେ ପ୍ରଥମେ cumulative frequency (c.f.) ବାହାର କରାଯାଏ।

m = n/2
Md = l + ((m−c.f.)/f) × i

ଉଦାହରଣରେ n=60. ତେଣୁ:

m=n/2=60/2=30

ସାରଣୀର cumulative frequency ଦେଖି 30ତମ observation ଥିବା class କୁ Median class ଭାବେ ନିଆଯାଏ। Source ର ଗଣନା ଅନୁସାରେ median class ହେଉଛି 30–40.

Md = l + ((m−c.f.)/f)×i
ଏଠାରେ formula ରେ ପ୍ରତ୍ୟେକ ମାନ କେଉଁଠୁ ଆସିଲା ତାହା ସାରଣୀରୁ ଚିହ୍ନଟ କରିବା—ଏହା ହେଉଛି ପରୀକ୍ଷାର ମୁଖ୍ୟ ପଦକ୍ଷେପ।

5.2.3 ବହୁଳକ — Mode

ଯେଉଁ ମାନଟି ସର୍ବାଧିକ ଥର ଘଟେ, ତାହାକୁ ବହୁଳକ (Mode) କୁହାଯାଏ।

ଉଦାହରଣ: 3, 5, 7, 3, 8, 5, 8, 7 ରେ ଏକାଧିକ ମାନ ସମାନ ଆବୃତ୍ତିରେ ଥାଇପାରେ; ତେଣୁ ଦିଆଯାଇଥିବା distribution କୁ ଭଲଭାବେ ଦେଖିବା ଆବଶ୍ୟକ।

Grouped data ରେ ସର୍ବାଧିକ frequency ଥିବା class କୁ modal class କୁହାଯାଏ।

Mo = 3Md − 2M
ଏହି empirical relation ତିନିଟି ମାପ—Mode, Median ଓ Mean—ମଧ୍ୟରେ ସମ୍ପର୍କ ଦେଖାଏ।

📝 ଉଦାହରଣ ୨୦ — Empirical Relation

ଯଦି Mean = M ଏବଂ Median = Md, ତେବେ:

Mo = 3Md − 2M
1
ଦିଆଯାଇଥିବା Mean ଓ Median ର ମାନ formula ରେ ବସାନ୍ତୁ।
2
ପ୍ରଥମେ 3Md ନିର୍ଣ୍ଣୟ କରନ୍ତୁ।
3
ତାହାରୁ 2M ବିୟୋଗ କରନ୍ତୁ।
ବହୁଳକ: Mo = 3Md − 2M
