ସମାନ୍ତର ପ୍ରଗତି

Arithmetic Progression — A.P.

ଏହି ପାଠରେ କ୍ରମ (Sequence), ସମାନ୍ତର ପ୍ରଗତି (A.P.), ସାଧାରଣ ଅନ୍ତର, n-ତମ ପଦ, ପ୍ରଥମ n ପଦର ଯୋଗ, ପଦଗୁଡ଼ିକର ଗୁଣଧର୍ମ, ଅନ୍ତର ସୂତ୍ର, ସିଗ୍ମା ଚିହ୍ନ, ପ୍ରାକୃତିକ/ବିଜୋଡ଼/ଜୋଡ଼ ସଂଖ୍ୟାର ଯୋଗ, ବର୍ଗ ଓ ଘନର ଯୋଗ ଏବଂ ସମାନ୍ତର ମାଧ୍ୟମକୁ ଧାପେ ଧାପେ ବୁଝାଯାଇଛି।

🎯 ପାଠର ଧାରା: କ୍ରମ → ପ୍ରଗତି → ସମାନ୍ତର ପ୍ରଗତି → ସାଧାରଣ ଅନ୍ତର → n-ତମ ପଦ → n ପଦର ଯୋଗ → ଗୁଣଧର୍ମ → ଅନ୍ତର ସୂତ୍ର → ବିଶେଷ ଯୋଗ → ସିଗ୍ମା → ସମାନ୍ତର ମାଧ୍ୟମ → ଅଭ୍ୟାସ

୦୧ କ୍ରମ (Sequence) କ’ଣ?

👨‍🏫
ପ୍ରଥମେ ଏହାକୁ ବୁଝିବା। କିଛି ସଂଖ୍ୟାକୁ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ କ୍ରମରେ ଲେଖିଲେ ତାହାକୁ କ୍ରମ କୁହାଯାଏ। ଉଦାହରଣ — 2, 4, 6, 8, … କିମ୍ବା 1, 3, 5, 7, … । କ୍ରମର ପ୍ରତ୍ୟେକ ସଂଖ୍ୟାକୁ ପଦ (term) କୁହାଯାଏ।

a = t₁

ଦ୍ୱିତୀୟ ପଦ

t₂

n-ତମ ପଦ

tₙ

ସାଧାରଣ ପଦ

କ୍ରମର ଯେକୌଣସି ପଦକୁ tₙ ଭାବରେ ଦର୍ଶାଯାଏ।

୦୩ ସମାନ୍ତର ପ୍ରଗତି (A.P.)

ପରିଭାଷା

ଯେଉଁ କ୍ରମରେ ପ୍ରତ୍ୟେକ ପଦ ଓ ତା’ର ପୂର୍ବ ପଦର ଅନ୍ତର ସମାନ ଥାଏ, ସେହି କ୍ରମକୁ ସମାନ୍ତର ପ୍ରଗତି କୁହାଯାଏ। ଏହି ସମାନ ଅନ୍ତରକୁ ସାଧାରଣ ଅନ୍ତର (Common Difference), d କୁହାଯାଏ।

a
→ + d →
a+d
→ + d →
a+2d
→ + d →
a+3d
→ … →
a+(n−1)d
t₁=a,   t₂=a+d,   t₃=a+2d,   …   tₙ=a+(n−1)d

ସାଧାରଣ ଅନ୍ତର

d=t₂−t₁=t₃−t₂=…

ଧନାତ୍ମକ d

ପଦଗୁଡ଼ିକ ବଢ଼ୁଥିବା ଦେଖାଯାଏ।

ଋଣାତ୍ମକ d

ପଦଗୁଡ଼ିକ କମୁଥିବା ଦେଖାଯାଏ।

୦୪ ସାଧାରଣ ଅନ୍ତର କିପରି ବାହାର କରିବା?

➖
ଏବେ ଆମେ ପରବର୍ତ୍ତୀ point କୁ ଯିବା। A.P. ଚିହ୍ନଟ କରିବାର ସବୁଠାରୁ ସହଜ ଉପାୟ — ପରପର ପଦଦ୍ୱୟର ଅନ୍ତର ନିଅ ଏବଂ ସମାନ କି ନୁହେଁ ଦେଖ।

ଉଦାହରଣ ୧

ଦିଆଯାଇଛି: −18, −16, −14, −12, …

ନିର୍ଣ୍ଣୟ: ସାଧାରଣ ଅନ୍ତର d।

d = −16−(−18) = 2
d = −14−(−16) = 2
d = −12−(−14) = 2
∴ d = 2

ଉଦାହରଣ ୨

ଦିଆଯାଇଛି: −11, 0, 11, 22, 33, 44, …

d = 0−(−11)=11 = 11−0 = 22−11 = 11
∴ d = 11

ଉଦାହରଣ ୩ — ଭଗ୍ନାଂଶ କ୍ରମ

ପାଠ୍ୟର ଉଦାହରଣରେ ପରପର ପଦର ଅନ୍ତର ନେଇ d ନିର୍ଣ୍ଣୟ କରାଯାଇଛି। ଏଠାରେ ମୁଖ୍ୟ ନିୟମ:

d = t₂−t₁ = t₃−t₂

୦୫ A.P. ର n-ତମ ପଦ

ମୁଖ୍ୟ ସୂତ୍ର
tₙ = a + (n−1)d

ଏଠାରେ a = ପ୍ରଥମ ପଦ, d = ସାଧାରଣ ଅନ୍ତର, n = ପଦର କ୍ରମ ସଂଖ୍ୟା, tₙ = n-ତମ ପଦ।

1
ପ୍ରଥମ ପଦ ଲେଖ: a
2
ସାଧାରଣ ଅନ୍ତର ଚିହ୍ନଟ କର: d
3
ଯେଉଁ ପଦ ଚାହିଁଛ, ସେହି n ନିଅ।
4
ସୂତ୍ରରେ ବସାଅ: tₙ=a+(n−1)d

ଉଦାହରଣ — 2, 4, 6, 8, …

ଦିଆଯାଇଛି: a=2, d=2.

ନିର୍ଣ୍ଣୟ: 10ମ ପଦ।

t₁₀ = 2 + (10−1)×2
= 2+18 = 20
∴ t₁₀ = 20

୦୬ ପ୍ରଥମ n ପଦର ଯୋଗ

➕
ଏବେ ଆମେ ପଦଗୁଡ଼ିକର ଯୋଗ ଦିଗକୁ ଯିବା। A.P. ର ପ୍ରଥମ n ପଦର ଯୋଗକୁ Sₙ ଦ୍ୱାରା ଦର୍ଶାଯାଏ।
ମୁଖ୍ୟ ସୂତ୍ର
Sₙ = n/2 (a+l)

ଏଠାରେ l = ଶେଷ ପଦ।

l = a+(n−1)d
∴ Sₙ = n/2 [2a+(n−1)d]
Sₙ = a+(a+d)+(a+2d)+…+[a+(n−1)d]
2Sₙ = n(a+l)
Sₙ = n/2(a+l)
Sₙ = n/2[2a+(n−1)d]

୦୭ Sₙ ସୂତ୍ରର ଅର୍ଥ ବୁଝିବା

ଶେଷ ପଦ ଜଣା ଥିଲେ

Sₙ=n/2(a+l)

a = ପ୍ରଥମ ପଦ; l = ଶେଷ ପଦ; n = ପଦ ସଂଖ୍ୟା।

କିମ୍ବା

d ଜଣା ଥିଲେ

Sₙ=n/2[2a+(n−1)d]

a = ପ୍ରଥମ ପଦ; d = ସାଧାରଣ ଅନ୍ତର; n = ପଦ ସଂଖ୍ୟା।

ଉଦାହରଣ — 15 ରୁ 85 ପର୍ଯ୍ୟନ୍ତ ପୂର୍ଣ୍ଣ ସଂଖ୍ୟାର ଯୋଗ

ପାଠ୍ୟରେ ପ୍ରଥମେ n ନିର୍ଣ୍ଣୟ କରାଯାଇଛି:

n = (85−15)+1 = 71

ଏଠାରେ a=15, l=85.

S₇₁ = 71/2(15+85)
= 71/2 × 100 = 3550
∴ ଯୋଗ = 3550

ଯାଞ୍ଚ: ପଦ ସଂଖ୍ୟା 71 ଏବଂ ପ୍ରଥମ+ଶେଷ = 100, ତେଣୁ ସୂତ୍ର ସଠିକ୍ ଭାବରେ ବ୍ୟବହୃତ।

୦୮ A.P. ର ଗୁଣଧର୍ମ

ଗୁଣଧର୍ମ ୧

A.P. ର ଯେକୌଣସି ଦୁଇଟି ପଦ ଦିଆଯାଇଲେ, ସେମାନଙ୍କ ମଧ୍ୟରୁ ସମାନ ଦୂରତାର ପଦମାନଙ୍କ ସମ୍ବନ୍ଧ ଦେଖାଯାଏ।

ଗୁଣଧର୍ମ ୨

ଯଦି aₘ ଓ aₙ ଦୁଇଟି ପଦ, ତେବେ ସେମାନଙ୍କ ମଧ୍ୟରେ ପଦ ସଂଖ୍ୟାର ତାରତମ୍ୟ ଅନୁସାରେ ଅନ୍ତର ମିଳେ।

ଗୁଣଧର୍ମ ୩

ପାଠ୍ୟରେ ମଧ୍ୟପଦ ସମ୍ବନ୍ଧୀୟ ସୂତ୍ର ଭାବରେ ଦିଆଯାଇଛି:

tₘ₋ₙ + tₘ₊ₙ = 2tₘ
ମଧ୍ୟପଦ ନିୟମ
tₘ₋ₙ + tₘ₊ₙ = 2tₘ

ଅର୍ଥାତ୍ ମଧ୍ୟରେ ଥିବା ପଦଟି ତାହାର ଦୁଇ ପାର୍ଶ୍ୱର ସମାନ ଦୂରତାର ପଦମାନଙ୍କ arithmetic mean ଭଳି କାମ କରେ।

୦୯ A.P. ର ଦୁଇଟି ପଦରୁ ଅନ୍ୟ ପଦ

🔍
ଯଦି A.P. ର ଦୁଇଟି ପଦ ଦିଆଯାଇଛି, ତେବେ ସେହି ଦୁଇ ପଦରୁ a ଓ d ନିର୍ଣ୍ଣୟ କରି ଆମେ ଅନ୍ୟ ପଦ ବାହାର କରିପାରିବା।

ପଦ୍ଧତି

1
ପ୍ରତ୍ୟେକ ଦିଆଯାଇଥିବା ପଦ ପାଇଁ tₙ=a+(n−1)d ଲେଖ।
2
ଦୁଇଟି equation ମିଳାଇ a ଓ d ନିର୍ଣ୍ଣୟ କର।
3
ମିଳିଥିବା a,d କୁ ଆବଶ୍ୟକ n ରେ ବସାଅ।

୧୦ ନିର୍ଦ୍ଦିଷ୍ଟ ପଦ ପର୍ଯ୍ୟନ୍ତ ଯୋଗ

ଉଦାହରଣ — 2, 4, 6, 8, … ର ପ୍ରଥମ 50 ପଦର ଯୋଗ

ଦିଆଯାଇଛି: a=2, d=2, n=50.

ସୂତ୍ର:

S₅₀ = 50/2 [2(2)+(50−1)2]
=25[4+98]
=25×102=2550
∴ S₅₀ = 2550

ଉଦାହରଣ — 27, 24, 21, … ର ଯୋଗ 132 ହେଲେ n ନିର୍ଣ୍ଣୟ

ଦିଆଯାଇଛି: a=27, d=−3, Sₙ=132.

132 = n/2[2(27)+(n−1)(−3)]
132 = n/2(57−3n)
264 = 57n−3n²
3n²−57n+264=0

ପାଠ୍ୟରେ ଏହି quadratic equation ରୁ ଦୁଇଟି ସମ୍ଭାବ୍ୟ n ମଧ୍ୟରୁ ଯଥାଯଥ ପଦ ସଂଖ୍ୟା ବିଚାର କରାଯାଇଛି।

୧୧ ଅନ୍ୟ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ A.P. ଉଦାହରଣ

ଦିଆଯାଇଛି t₁₀ ଓ t₂₁

ଦୁଇଟି ପଦରୁ a ଓ d ନିର୍ଣ୍ଣୟ କରି ପରେ ଚାହିଁଥିବା Sₙ ବା ପଦ ବାହାର କରାଯାଏ।

ଦୁଇ ପଦର ଅନ୍ତର

tₘ ଓ tₙ ର relation ରେ (m−n)d ଆସେ।

ସମାନ ଦୂରତାର ପଦ

ମଧ୍ୟପଦକୁ ଘିରି equal-distance terms ର ଯୋଗ = 2 × middle term.

ମନେ ରଖନ୍ତୁ
tₙ=a+(n−1)d
tₘ−tₙ=(m−n)d
tₘ₋ₙ+tₘ₊ₙ=2tₘ

୧୨ ଅନ୍ତର ସୂତ୍ର (Difference Formula)

➖
ଏବେ ଆମେ ଏକ ବିଶେଷ ଯୋଗକୁ ଦେଖିବା, ଯେଉଁଠାରେ ପ୍ରତ୍ୟେକ ପଦକୁ ଦୁଇଟି consecutive ସଂଖ୍ୟାର ଅନ୍ତର ଭାବରେ ଲେଖିପାରିବା।
ମୁଖ୍ୟ ପ୍ୟାଟର୍ନ
1/[n(n+1)] = 1/n − 1/(n+1)

ଉଦାହରଣ ୧୦ — 1/(1×2)+1/(2×3)+…

ଧାପ ୧: ପ୍ରତ୍ୟେକ ପଦକୁ difference form ରେ ଲେଖ।

1/(1×2)=1−1/2
1/(2×3)=1/2−1/3
1/(3×4)=1/3−1/4
…
1/[n(n+1)] = 1/n−1/(n+1)

ଯୋଗ କଲେ ମଧ୍ୟବର୍ତ୍ତୀ terms କଟିଯାଏ।

Sₙ = 1−1/(n+1)=n/(n+1)
ଏହାକୁ telescoping/difference ଭାବରେ ସହଜରେ ଯୋଗ କରାଯାଏ।

୧୩ ପ୍ରାକୃତିକ ସଂଖ୍ୟାର ଯୋଗ

ସୂତ୍ର
1+2+3+…+n = n(n+1)/2

ସୂତ୍ରକୁ A.P. ଭାବରେ ବୁଝିବା

ଏଠାରେ a=1, d=1, ଶେଷ ପଦ=n.

Sₙ=n/2(1+n)=n(n+1)/2
∴ 1 ରୁ n ପର୍ଯ୍ୟନ୍ତ ସଂଖ୍ୟାର ଯୋଗ = n(n+1)/2

୧୪ ବିଜୋଡ଼ ସଂଖ୍ୟାର ଯୋଗ

ସୂତ୍ର
1+3+5+…+(2n−1)=n²

୧୫ ଜୋଡ଼ ସଂଖ୍ୟାର ଯୋଗ

ସୂତ୍ର
2+4+6+…+2n = n(n+1)

ଏହା A.P. ଅଟେ: a=2, d=2, n-ତମ ପଦ=2n.

Sₙ=n/2[2+(2n)]
=n(n+1)
∴ ପ୍ରଥମ n ଜୋଡ଼ ସଂଖ୍ୟାର ଯୋଗ = n(n+1)

୧୬ ପ୍ରାକୃତିକ ସଂଖ୍ୟାର ବର୍ଗର ଯୋଗ

ସୂତ୍ର
1²+2²+3²+…+n² = n(n+1)(2n+1)/6

ଏହି formula କୁ ପାଠ୍ୟରେ algebraic manipulation ଦ୍ୱାରା derive କରାଯାଇଛି। ପରୀକ୍ଷା ପାଇଁ formula ଏବଂ ତା’ର symbols ର ଅର୍ଥ ମନେ ରଖନ୍ତୁ।
Σn² = n(n+1)(2n+1)/6

୧୭ ପ୍ରାକୃତିକ ସଂଖ୍ୟାର ଘନର ଯୋଗ

ସୂତ୍ର
1³+2³+3³+…+n³ = [n(n+1)/2]²

୧୮ ସିଗ୍ମା (Σ) ଚିହ୍ନ

Σ
ଅନେକ terms ର ଯୋଗକୁ ସଂକ୍ଷେପରେ ଲେଖିବା ପାଇଁ Σ ଚିହ୍ନ ବ୍ୟବହାର କରାଯାଏ।
ମୁଖ୍ୟ ରୂପ
1+2+3+…+n = Σn = n(n+1)/2
1²+2²+…+n² = Σn² = n(n+1)(2n+1)/6
1³+2³+…+n³ = Σn³ = [n(n+1)/2]²
ସହଜ ଭାବରେ: Σ ର ଅର୍ଥ ହେଉଛି “ନିର୍ଦ୍ଦିଷ୍ଟ ନିୟମ ଅନୁସାରେ terms ଗୁଡ଼ିକୁ ଯୋଗ କରିବା”।

୧୯ ସମାନ୍ତର ପ୍ରଗତି ଓ ସମାନ୍ତର ମାଧ୍ୟମ

ARITHMETIC MEAN
A.M. = (a+b)/2

ଦୁଇଟି ସଂଖ୍ୟା a ଓ b ମଧ୍ୟରେ ସମାନ୍ତର ମାଧ୍ୟମ ହେଉଛି ସେମାନଙ୍କ ଯୋଗର ଅର୍ଦ୍ଧ।

ଉଦାହରଣ — 7 ଓ 15 ର A.M.

M=(7+15)/2=22/2=11
∴ A.M. = 11

୨୦ ଦୁଇଟି ସଂଖ୍ୟା ମଧ୍ୟରେ A.M. ବସାଇବା

📏
ଯଦି a ଓ b ମଧ୍ୟରେ nଟି arithmetic means ବସାଇବାକୁ ହୁଏ, ତେବେ ମିଳୁଥିବା ସମ୍ପୂର୍ଣ୍ଣ କ୍ରମଟି ଏକ A.P. ହେବ।

ମୁଖ୍ୟ ଧାରଣା
d = (b−a)/(n+1)

ତା’ପରେ x₁=a+d, x₂=a+2d, … ଭାବରେ means ଗୁଡ଼ିକ ମିଳେ।

ଉଦାହରଣ — 2 ଓ 62 ମଧ୍ୟରେ 3ଟି A.M.

ଦିଆଯାଇଛି: a=2, b=62, n=3.

d=(62−2)/(3+1)=60/4=15
x₁=2+15=17
x₂=2+2×15=32
x₃=2+3×15=47
∴ 3ଟି A.M. = 17, 32, 47

ଯାଞ୍ଚ: 2, 17, 32, 47, 62 ମଧ୍ୟରେ ପ୍ରତ୍ୟେକ consecutive difference = 15.

୨୧ ଏକାଧିକ A.M. — ଭିଜୁଆଲ୍ ଧାରଣା

ପାଠ୍ୟରେ 2 ଓ 62 ମଧ୍ୟରେ 3ଟି ଓ 4ଟି A.M. ର ଉଦାହରଣ ଦିଆଯାଇଛି। 4ଟି A.M. ପାଇଁ ମଧ୍ୟ ସେହି d=(b−a)/(n+1) ଧାରଣା ବ୍ୟବହାର କରାଯାଏ।

୨୨ ପରୀକ୍ଷା ପାଇଁ ସମ୍ପୂର୍ଣ୍ଣ ପଦ୍ଧତି

⚠️ ଗଣିତରେ ସାଧାରଣ ଭୁଲ:
  • d = t₁−t₂ ନୁହେଁ; ପରବର୍ତ୍ତୀ ପଦ − ପୂର୍ବ ପଦ ନିଅ: d=t₂−t₁.
  • n-ତମ ପଦରେ (n−1) ଲେଖିବା ଭୁଲନ୍ତୁ ନାହିଁ।
  • Sₙ ରେ n/2 ଗୁଣନ କରିବାକୁ ଭୁଲନ୍ତୁ ନାହିଁ।
  • ଋଣାତ୍ମକ d ଥିଲେ sign ସଠିକ୍ ରଖ।
  • A.M. ବସାଇବା ବେଳେ n+1 ଦ୍ୱାରା b−a କୁ ଭାଗ କର।
  • Formula ଲେଖିବା ପରେ ପ୍ରତ୍ୟେକ numerical substitution ଅଲଗା ଧାପରେ କର।

ଅଭ୍ୟାସ 3(a)

ପଦ ନିର୍ଣ୍ଣୟ, ସାଧାରଣ ଅନ୍ତର, A.P. ଚିହ୍ନଟ, n-ତମ ପଦ ଏବଂ ଦିଆଯାଇଥିବା A.P. ର ପଦ/ଯୋଗ ଭିତ୍ତିକ ପ୍ରଶ୍ନ।

ଅନ୍ତର ଭିତ୍ତିକ ଯୋଗ, ସିଗ୍ମା, ବର୍ଗ/ଘନ ଯୋଗ, A.M. ଏବଂ ଦିଆଯାଇଥିବା ସଂଖ୍ୟାରେ A.M. ବସାଇବା।
