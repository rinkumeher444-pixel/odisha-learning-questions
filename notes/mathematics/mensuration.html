1. ବୃତ୍ତର ମୂଳ ଧାରଣା

କେନ୍ଦ୍ର: O
ବ୍ୟାସାର୍ଦ୍ଧ: କେନ୍ଦ୍ରରୁ ପରିଧି ପର୍ଯ୍ୟନ୍ତ ଦୂରତା r.
ବ୍ୟାସ: d = 2r.
ପରିଧି: ବୃତ୍ତର ଚାରିପଟିର ସମ୍ପୂର୍ଣ୍ଣ ଲମ୍ବ।

2. ବୃତ୍ତର ପରିଧି

C = πd = 2πr

C = 2πr
ସହଜରେ: ବ୍ୟାସ ଦିଆଥିଲେ πd, ବ୍ୟାସାର୍ଦ୍ଧ ଦିଆଥିଲେ 2πr ବ୍ୟବହାର କରନ୍ତୁ।

3. ଚାପର ଲମ୍ବ

ପରୀକ୍ଷା ପଏଣ୍ଟ: θ°/360° ଅଂଶ ନେବା ଭୁଲିବେ ନାହିଁ।

4. Sector, Minor Sector ଓ Major Sector

Sector: ଦୁଇଟି ବ୍ୟାସାର୍ଦ୍ଧ ଓ ସେମାନଙ୍କ ମଧ୍ୟର ଚାପ ଦ୍ୱାରା ଘେରା ଅଞ୍ଚଳ।

Minor Sector: ଛୋଟ ଅଂଶ।
Major Sector: ବଡ଼ ଅଂଶ।
Sector perimeter = 2r + L

5. କ୍ଷେତ୍ରଫଳ: ବୃତ୍ତ ଓ Sector

ବୃତ୍ତ

A = πr²

Sector

A = (θ/360°) × πr²
ପ୍ରଥମେ ଚିତ୍ର ଚିହ୍ନଟ କରନ୍ତୁ। ପୂରା ବୃତ୍ତ ହେଲେ πr²; sector ହେଲେ θ/360° ଅଂଶ ନିଅନ୍ତୁ।

Circular Annulus

A = π(R² − r²)
ବାହ୍ୟ ବୃତ୍ତର କ୍ଷେତ୍ରଫଳ − ଭିତର ବୃତ୍ତର କ୍ଷେତ୍ରଫଳ।

6. Segment ର କ୍ଷେତ୍ରଫଳ — ଚିତ୍ର ଦେଖି ଭାବନ୍ତୁ

Sector ଓ Segment ଏକ ନୁହେଁ। ପ୍ରଶ୍ନର ଚିତ୍ର ଅନୁସାରେ କେଉଁ ଅଞ୍ଚଳ ଚାହିଁଛି ତାହା ପ୍ରଥମେ ଚିହ୍ନଟ କରନ୍ତୁ।

7. ନିୟମିତ ଘନ ଓ ପୃଷ୍ଠଫଳ

ଘନର ବାହ୍ୟ ଭାଗକୁ ପୃଷ୍ଠ ଭାବରେ ବୁଝନ୍ତୁ। କେଉଁ ପୃଷ୍ଠ ଗଣନା କରିବାକୁ ହେବ—ପ୍ରଥମେ ସେହିଟା ଚିହ୍ନଟ କରନ୍ତୁ।

9. Right Circular Cylinder

15. PDF ଆଧାରିତ Worked Examples

1ବୃତ୍ତର ପରିଧି — r = 21 cm

ଦିଆଯାଇଛି: r = 21 cm, π = 22/7

ବାହାର କରିବା: ପରିଧି

C = 2πr

ପଦକ୍ଷେପ ୧: C = 2 × 22/7 × 21

ପଦକ୍ଷେପ ୨: 21 ÷ 7 = 3

ପଦକ୍ଷେପ ୩: C = 2 × 22 × 3 = 132 cm

ଉତ୍ତର: 132 cm

2ଚାପର ଲମ୍ବ — ସାଧାରଣ ପଦକ୍ଷେପ

ଦିଆଯାଇଛି: r ଓ θ°

ବାହାର କରିବା: L

L = (θ/360°) × 2πr

ପ୍ରଥମେ ପୂର୍ଣ୍ଣ ପରିଧି 2πr ନିଅନ୍ତୁ → ତାହାର θ°/360° ଅଂଶ ନିଅନ୍ତୁ → L ପାଆନ୍ତୁ।

L = θπr/180°

3Annulus ର କ୍ଷେତ୍ରଫଳ

ଦିଆଯାଇଛି: ବାହ୍ୟ R, ଭିତର r

ବାହାର କରିବା: ବଳୟ ଅଞ୍ଚଳ

A = πR² − πr² = π(R² − r²)
ଉତ୍ତର: π(R² − r²)

4ବେଲନ — ବକ୍ର ପୃଷ୍ଠଫଳ

ଦିଆଯାଇଛି: r, h

ବାହାର କରିବା: CSA

CSA = 2πrh

ପରିଧି = 2πr → ଉଚ୍ଚତା h ସହ ଗୁଣ → 2πrh.

ଉତ୍ତର: 2πrh

5ଶଙ୍କୁ — l ନିର୍ଣ୍ଣୟ

ଦିଆଯାଇଛି: r, h

ବାହାର କରିବା: l

l² = h² + r²

ପଦକ୍ଷେପ: l = √(h² + r²)

ଉତ୍ତର: l = √(h² + r²)

ଦୀର୍ଘ / Problem-solving

  1. ଦିଆଯାଇଥିବା r ରୁ ବୃତ୍ତର ପରିଧି ନିର୍ଣ୍ଣୟ କର।
  2. r ଓ θ° ରୁ ଚାପର ଲମ୍ବ ନିର୍ଣ୍ଣୟ କର।
  3. R ଓ r ରୁ annulus କ୍ଷେତ୍ରଫଳ ନିର୍ଣ୍ଣୟ କର।

  6. ଗୋଲକର r ରୁ ପୃଷ୍ଠଫଳ ଓ ଆୟତନ ନିର୍ଣ୍ଣୟ କର।
